# 🤖 BotLeague Frontend Assignment

A pixel-perfect and responsive frontend implementation of the provided Figma design, built using **React**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**. The project focuses on clean component architecture, responsive layouts, smooth animations, and modern UI/UX practices.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/prerna-255/Assignment_botmakers.git
```

Move into the project

```bash
cd Assignment_botmakers
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open your browser

```
http://localhost:5173
```

---

# 📦 Production Build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
